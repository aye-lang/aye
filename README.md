# Ore

Ore is a systems programming language: no garbage collector, no borrow
checker, no exceptions, no macros. Memory is managed through explicit
`Allocator` parameters and `defer`/`errdefer`. The syntax is Go-like (braces,
`name: Type`, no semicolons). Integer overflow and out-of-bounds access trap in
checked builds.

Design doc: <https://claude.ai/code/artifact/f86fcc65-a2d3-442d-b96d-fdbe637af2dc>

This repository holds **stage0**: a compiler written in Rust that emits C and
builds it with clang. It implements a first slice of the language (see
[Supported subset](#supported-subset)).

## Build and run

Requirements: Rust (cargo), and `clang` on `PATH`. Developed on macOS arm64
with Apple clang 17.

```sh
cargo build --release
./target/release/ore run tests/cases/hello.ore
```

Commands:

```
ore build <file.ore> [-o out] [--mode debug|safe|fast]   # executable (default name: file stem)
ore run <file.ore> [--mode debug|safe|fast]               # build to a temp file and run
ore emit-c <file.ore> [--mode debug|safe|fast]            # print the generated C
```

| Mode    | clang flags | Runtime checks (overflow, bounds, casts, div by zero) |
|---------|-------------|--------------------------------------------------------|
| `debug` | `-O0 -g`    | on (default)                                           |
| `safe`  | `-O2 -g`    | on                                                     |
| `fast`  | `-O2`       | off                                                    |

All modes compile with `-std=gnu11 -fwrapv -fno-strict-aliasing`. Checks are
generated by Ore, not left to C semantics. A failed check prints
`file:line:col: panic: <reason>` to stderr and aborts. Compile errors are
reported as `file:line:col: error: <message>`.

## Example

```ore
extern fn puts(s: [*]u8) i32

struct Point { x: i32, y: i32 }

fn dot(a: Point, b: Point) i32 {
    return a.x * b.x + a.y * b.y
}

pub fn main() {
    defer @println("bye")
    puts("hello".ptr)
    let p = Point { x: 1, y: 2 }
    @println(dot(p, p))
    var xs = [4]i64{1, 2, 3, 4}
    for i in 0..xs.len {
        xs[i] *= 10
    }
    let tail = xs[2..]
    @println(tail[0] + tail[1])
}
```

## Supported subset

- Top level: `fn`, `pub fn`, `extern fn` (C functions), `struct Name { ... }`.
  The entry point is `pub fn main()`.
- Statements: `let`, `var`, `=` and compound assignment (`+= -= *= /= %= +%= -%= *%=`),
  `if`/`else`, `while`, `for i in lo..hi`, `break`, `continue`, `return`,
  `defer`, nested blocks, call statements.
- Expressions: integer/float/bool/string/char literals, `+ - * / %` (checked),
  `+% -% *%` (wrapping), comparisons, `&& || !`, unary `-`, calls, struct
  literals, field access, `as` numeric casts, arrays `[3]i32{1, 2, 3}`,
  bounds-checked indexing, slicing `a[lo..hi]`, `.len`, `.ptr`.
- Types: `i8..i64 u8..u64 isize usize f32 f64 bool`, structs, `[N]T`, `[]T`,
  `[*]T` (FFI pointer).
- Output: `@print(x)` / `@println(x)` / `@println()` for integers, floats,
  bools and `[]u8` strings; or call libc through `extern fn`.

Not yet supported (reported as errors): generics/`comptime`, `enum`/`match`,
error unions (`!T`, `try`, `catch`, `errdefer`), `?T`, `*T` pointers,
`interface`/`dyn`, `import`, allocators/std, `test` blocks, `extern struct`,
global variables.

See [`docs/grammar.ebnf`](docs/grammar.ebnf) for the grammar and
[`docs/decisions.md`](docs/decisions.md) for choices not fixed by the design doc.

## Compiler pipeline

`src/lexer.rs` → `src/parser.rs` (`src/ast.rs`) → `src/sema.rs` (typed AST) →
`src/oir.rs` (OIR: flattened typed IR; `defer` expanded, checks explicit) →
`src/cgen.rs` (C) → clang, driven by `src/driver.rs`.

## Tests

```sh
cargo test
```

`tests/golden.rs` compiles every `tests/cases/*.ore` in debug, safe and fast
mode, runs it and compares stdout with `*.out`; when a `*.panic` file exists
the program must abort with exactly that stderr (debug and safe only). Every
`tests/errors/*.ore` must fail to compile with the message in `*.err`.
